# Roadmap — ANAK

Scaffold Next.js + TypeScript + Tailwind, carpetas, rutas placeholder, stubs y documentación.

- Pendiente: logo, tipografías, fotos, copy y maquetación de las secciones ANAK (clases, eventos especiales, matcha, retos, Balance Club).

## 3. Tree visual

Look editorial en `/tree` con links ANAK (clases, eventos, matcha, retos, Balance Club). Sin invites de grupos pagos en el cliente.

## 4. Eventos especiales + pagos + emails

Landing de eventos especiales, registro, checkout Mercado Pago, emails (Resend).

## 5. Admin completo

Auth real, CRUD de eventos, inscritos, correos, export CSV y métricas de resumen.

## 6. Balance Club / CRM / sync

Balance Club, invites server-side si aplican, sync con CRM/reservas.
